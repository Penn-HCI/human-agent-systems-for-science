description: How to write any documentation or notes in this project (claude-notes/, notes_for_students.md, READMEs, docstrings). Use whenever writing or editing docs, and whenever the user makes or changes a design decision, which gets recorded in claude-notes/decisions.md.
---

Docs here jog one's memory about intent; they don't document the system comprehensively.

- One point = about one sentence.
- Use the user's own wording wherever possible; don't expand it with your reasoning or implementation details.
- When something changes, edit or replace the old line; don't append a contradiction.
- Record design decisions in `claude-notes/decisions.md`, under the matching `##` heading.
