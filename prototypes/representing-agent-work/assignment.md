In the future, maybe some scientific discoveries come from agents that run entirely autonomously. In truth, agents seem to be getting _much better_ at doing this kind of work.

But consider for a moment — what do people _do_ with a finding that's been generated by an agent?

Some findings will stand on their own. If an agent can discover a theorem and prove it with Lean, then it can add it to a repository of theorems that can be used in future proofs. Maybe it needs to be cleaned up and optimized, but it is more or less ready to be useful as is.

Other findings, while not self-verifying, will be easy enough to check. Maybe the agent finds a factoid from an old book, and shows you the clipping --- great, you can use this insight. Or it does some stats on dataset it finds, and the stats code is straightforward, and the dataset is good.

Other findings still we don't really care if they're accurate. If an agent finds a hypothesized new drug, if it's cheap enough, it can synthesize the drug and try it out in the lab, testing it's conclusions against the real world.

But I think for a significant amount of these discoveries, we will care if they are accurate and they won't be easy to verify. Have you ever read a paper and said "These claims look cool!" only to get partly in to the paper and say "Oh... this isn't very good." The data has unfortunate stipulations, the methods don't follow best practices, or there are just obvious alternative explanations that haven't been ruled out. The claims might be technically correct, but the force has been taken out of them by the details.

The same thing can happen with agents. And so in this assignment we'll investigate different communication patterns by which we could help people get to the bottom of what specifically an agent has done so that they can get from "This looks cool!" to either "It sure is!" or "This isn't looking good..."
