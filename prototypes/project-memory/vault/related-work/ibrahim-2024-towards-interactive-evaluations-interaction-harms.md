# Interactive evaluations for interaction harms (Ibrahim et al., 2024)

## Summary
A position paper arguing for evaluating AI through sustained human interaction. Indirect: it doesn't test the question, but argues static output tests miss harms that only show up in interaction.

## Relevant findings
- **Static, model-only tests miss harms that emerge over sustained interaction.**

> [!quote]- Source: Ibrahim et al. 2024, p. 1
> "Current AI evaluation methods, which rely on static, model-only tests, fail to account for harms that emerge through sustained human-AI interaction."
>
> [[sources/ibrahim-2024-towards-interactive-evaluations-interaction-harms.pdf]] · https://arxiv.org/abs/2405.10632
