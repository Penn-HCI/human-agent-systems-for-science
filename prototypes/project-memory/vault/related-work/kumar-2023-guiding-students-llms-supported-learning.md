# Guiding students' LLM use (Kumar et al., 2023)

## Summary
Classroom (N=145) and online (N=356) experiments on how guidance for using an LLM affects learners' performance, confidence and trust. Indirect: the help that most improved scores was not the help that built the most trust.

## Relevant findings
- **Direct LLM answers slightly improved performance, while refining students' own solutions built more trust.**

> [!quote]- Source: Kumar et al. 2023, p. 1
> "Direct LLM answers marginally improved performance, while refining student solutions fostered trust."
>
