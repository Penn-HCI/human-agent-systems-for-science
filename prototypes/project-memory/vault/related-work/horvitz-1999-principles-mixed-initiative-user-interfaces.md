# Principles of mixed-initiative user interfaces (Horvitz, 1999)

## Summary
Design principles for combining automated agents with direct manipulation, shown in an email-scheduling assistant. Doesn't test the question directly; it argues that a wrong guess need not hurt the user if the interface makes it easy to fix.

## Relevant findings
- **A wrong AI guess can still help if the user can refine it.**

> [!quote]- Source: Horvitz 1999, p. 2
> "Even when Lookout guesses incorrectly, the user is placed in an approximately correct position in the calendar and can refine an approximate guess about the implied appointment."
>
> [[sources/horvitz-1999-principles-mixed-initiative-user-interfaces.pdf]]

## Connection to our investigations
Offers one reason [[ai-output-quality]] and task success could come apart in [[output-vs-interaction-quality-crossword]]: people can work from imperfect suggestions.
