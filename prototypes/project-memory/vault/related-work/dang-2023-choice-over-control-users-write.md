# Choice over control (Dang et al., 2023)

## Summary
A user study of 129 people writing with GPT-3 under four interface variants. It doesn't test the question directly; it only shows that the interface changes how helpful the same model feels.

## Relevant findings
- **With the same model, showing one suggestion instead of three was rated less helpful and more distracting.**

> [!quote]- Source: Dang et al. 2023, p. 6
> "Single suggestions were rated as significantly more distracting (𝑥=1.95, p<0.005), less helpful (𝑥=0.60, p=0.02)"
>
> [[sources/dang-2023-choice-over-control-users-write.pdf]] · https://doi.org/10.1145/3544548.3580969
