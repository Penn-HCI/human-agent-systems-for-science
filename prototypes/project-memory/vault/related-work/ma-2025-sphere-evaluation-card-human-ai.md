# SPHERE evaluation card (Ma et al., 2025)

## Summary
A review of how 39 human-AI system papers were evaluated. It doesn't test the question (indirect); it notes that benchmark results and user preferences may not track user task performance.

## Relevant findings
- **Benchmarks and user preferences may not track how well users actually do on the task.**
